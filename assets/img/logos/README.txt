DROP OFFICIAL RECOGNITION LOGOS HERE
====================================
The "Certified & approved" scrolling strip and the "certified by" grid on the
home page automatically use a logo if you place a PNG (transparent background
works best) with the matching name in this folder. Until a file exists, that
item shows the body's name as a clean text chip instead.

Use only logos your company is licensed / permitted to display.

Expected filenames:
  iso.png         -> ISO 9001:2015
  sirim.png       -> SIRIM Malaysia
  sirim-eco.png   -> SIRIM Eco-Label
  tuv.png         -> TUV SUD PSB
  mcma.png        -> Malaysian Cable Manufacturers Association (MCMA)
  teeam.png       -> TEEAM
  sni.png         -> SNI (Indonesia)
  tnb.png         -> Tenaga Nasional Berhad (TNB)
  st.png          -> Suruhanjaya Tenaga (Energy Commission)
  sesb.png        -> Sabah Electricity (SESB)
  sarawak.png     -> Sarawak Energy
  bomba.png       -> BOMBA (Fire & Rescue)
  jkr.png         -> Jabatan Kerja Raya (JKR)

Tip: wide or square transparent PNGs ~240px tall look best. They sit on white
chips, so coloured logos show clearly on the dark theme.
